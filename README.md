# GitHub Copilot Customer Newsletter

This repository hosts a **recurring customer newsletter** summarizing GitHub Copilot and
broader GitHub platform updates. Every item is sourced from the **public
[GitHub Changelog](https://github.blog/changelog/)** and other publicly available GitHub
documentation, blog posts, and announcements.

## Where to read it

Each edition is published as a **GitHub Discussion** in the **Customer Newsletter**
category.

📬 **[Browse the newsletter archive →](https://github.com/liamvoge/copilot-customer-newsletter/discussions/categories/customer-newsletter)**

You can also see all Discussions in this repo here:
[Discussions tab](https://github.com/liamvoge/copilot-customer-newsletter/discussions).

## What's in each edition

- **Executive Summary** — the headline stories of the period in plain language
- **Table of Contents** — jump straight to what's relevant to you
- Grouped sections covering, as relevant to the period:
  - Urgent billing, governance, or deadline items
  - Copilot platform updates (CLI, IDEs, new surfaces and apps)
  - Autonomous and agentic capabilities
  - Model availability
  - Security and governance
  - GitHub platform updates beyond Copilot
  - Resources, best practices, webinars, events, and recordings

Every factual claim links back to its public source so you can read the original
announcement yourself.

## Who it's for

A mixed audience: engineering leaders, security leaders, and individual developers —
some already on GitHub, some evaluating it, with varying levels of AI adoption maturity.
The goal is to **educate**: describe what shipped and why it matters, and
let the value speak for itself.

## Subscribing and participating

- **Watch this repository** (Watch → Custom → Discussions) to get notified when a new
  edition is published.
- The **Customer Newsletter** category is an *Announcement* category, so only maintainers
  can start new threads — but **anyone can comment**. Questions, corrections, and requests
  for deeper dives are welcome on any edition.

## Content policy

This repository is **public**. It contains **no customer names, no account or contract
details, no deal or pipeline information, and no internal company data** of any kind.
Content is limited to publicly announced GitHub product news and publicly available
resources.

## Disclaimer

This is a personally curated newsletter. It is not an official GitHub publication, and it
is not a substitute for the official
[GitHub Changelog](https://github.blog/changelog/) or
[GitHub Docs](https://docs.github.com/). Product availability, pricing, and behavior can
change after publication — always confirm against the linked primary source.
